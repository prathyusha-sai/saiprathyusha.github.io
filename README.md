# Portfolio — Sai Prathyusha Illendula

Personal portfolio site for a cybersecurity analyst (SC-200).

## Publish with GitHub Pages

1. Create a **public** repo named `<your-github-username>.github.io`
2. Upload `index.html` (and this README) to the repo root
3. Repo Settings → Pages → Deploy from branch → `main` / `/ (root)`
4. Live at `https://<your-github-username>.github.io`

Then link it in the LinkedIn Featured section and at the top of the resume.
